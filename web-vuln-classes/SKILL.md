# Web 漏洞类速查

每类只记四件事：**判定信号 → 无害探针 → 后果证实 → 假阳性**。目标：拿到一个疑似点，30 秒内判断要不要深挖。

> 完整流程见 `web-vuln-methodology`，学习顺序见 `vuln-learning-roadmap`。

## 1. IDOR / BOLA / 越权（最常见）

- **本质**：服务端没校验「这个对象属于当前用户」。
- **信号**：请求带 `id / uid / orderId / comment_id / memberId / orgCode / positionId` 等对象标识。
- **无害探针**：请求自己 id（基线）→ 换成他人 id（篡改）→ 对比响应。**必须做对照**。
- **后果证实**：读到/改到他人数据（200 + 他人数据）。
- **假阳性**：换 id 返回 403/404 且与基线一致 → 有归属校验。

## 2. SQL 注入

- **信号**：参数流入查询 → 报错/布尔/时序差异。
- **无害探针**：`'`（看报错）；`1 AND 1=1` vs `1 AND 1=2`（看布尔差异）；`sleep`（看时序）。
- **后果证实**：sqlmap 确认，或 error/boolean/union/time 差异稳定可复现。
- **假阳性**：报错来自别的层；差异只是缓存/随机数。全参数 + 对照组都无差异才排除。

## 3. XSS（反射/存储/DOM）

- **信号**：输入被回显且未转义。
- **无害探针**：`<img src=x onerror=alert(1)>`；上传 `.html`（存储型）。
- **后果证实**：弹窗/回调触发、可窃取 cookie。
- **假阳性**：输出被转义；content-type 不按 HTML 解析（如 `text/plain`）。

## 4. 文件上传

- **信号**：存在上传端点。
- **无害探针**：先证明「可写 + 可访问」（传合法文件看返回路径）。**先别传 shell。**
- **后果证实（仅靶场/书面授权）**：改名 `.php/.jsp/.ashx`、双 Content-Disposition，证明可解析。
- **假阳性**：扩展名/mime/白名单拦截；上传目录不执行脚本。

## 5. LFI / 路径遍历 / 任意文件读

- **信号**：参数是文件路径（`file=`、`path=`、`template=`）。
- **无害探针**：`../../../../etc/passwd`（Linux）/ `..\..\..\windows\win.ini`（Windows）。
- **后果证实**：读到预期目录之外的文件。
- **假阳性**：做了前缀固定/过滤 `../`。

## 6. SSRF

- **信号**：服务器代取 URL（`url=`、`callback=`、代理、webhook）。
- **无害探针**：指向受控回显地址；内网探测（`169.254.169.254` 云元数据）。
- **后果证实**：打到内网服务/云元数据拿临时凭证。
- **假阳性**：仅返回状态但未真正发起请求（要做带外对照）。

## 7. XXE

- **信号**：XML 上传/解析接口。
- **无害探针**：`<!DOCTYPE ... SYSTEM "file:///etc/passwd">` 外部实体读文件。
- **后果证实**：读到文件 / 发起 SSRF。
- **假阳性**：XML 解析器禁用外部实体。

## 8. SSTI

- **信号**：模板引擎注入（用户输入进模板）。
- **无害探针**：`{{7*7}}` 出 `49` 即命中。
- **后果证实**：执行代码/读文件（按引擎 payload 差异）。
- **假阳性**：输入被当纯文本渲染。

## 9. 反序列化

- **信号**：Java/.NET/PHP 反序列化入口，常配合已知组件（Shiro、Fastjson、Weblogic）。
- **后果证实（靶场）**：gadget 链触发 RCE。
- **假阳性**：无 gadget 链、对象被白名单过滤。

## 10. 命令注入

- **信号**：参数拼进系统命令（`ping`、`exec`、`system`）。
- **无害探针**：`; id`、`| whoami` 分隔符回显。
- **后果证实**：单次命令回显。
- **假阳性**：命令被转义/白名单。

## 11. 开放重定向

- **信号**：`redirect_url / url / next / returnUrl` 可控。
- **无害探针**：换成外域看 302 Location。
- **后果证实**：跳转外域（钓鱼/绕过 SSRF 白名单）。
- **假阳性**：跳转被固定到站内白名单。

## 12. 认证绕过

- **信号**：登录返回 `success`/bool/token。
- **无害探针**：`false -> true`、重放合法响应。
- **后果证实**：进入后台/受保护页。
- **假阳性**：服务端二次校验。

## 13. CSRF

- **信号**：敏感操作无 token/无 Origin 校验。
- **后果证实**：无 token 也能触发状态变更。
- **假阳性**：有 CSRF token / SameSite 严格 / Origin 校验。

## 14. 信息泄露

- **信号**：`.git/`、`.svn/`、`backup.zip`、debug 页、报错堆栈、JS source map。
- **后果证实**：拿到源码/配置/凭据/内网信息。

## 15. 业务逻辑

- **信号**：金额、券、订单、奖励、限购端点。
- **无害探针**：小数金额、并发下单、越权改价、拆券叠加。
- **后果证实**：半价、超发券、绕过限购。
- **假阳性**：服务端原子性重校验。

## 16. 弱口令 / 默认口令

- **信号**：登录/后台/管理接口。
- **无害探针**：厂商手册默认账密。**失败即停，避免锁定。**

---

**通用纪律**：一次异常响应 ≠ 漏洞；判定都要「基线 vs 篡改」对照 + 可复现 + 影响说明。
